# 要件定義書 REQ-UC002：タスク更新

## 基本情報

- **要求レベル**：Must（必須）
- **利用者**：研修受講者（4名）

## 概要

研修受講者が登録済みタスクの内容を確認・変更し、変更後の情報を保存できるようにする。

## ユーザーストーリー

- **誰として**：研修受講者として
- **何をしたいか**：登録済みタスクの内容を確認し、必要に応じて更新したい
- **その理由**：作業内容や期限の変更をタスク情報に反映し、計画を正確に保つため

## As-Is（現状）

現行画面はReact/Viteの初期テンプレートであり、タスク一覧、タスク編集画面、タスク情報の更新機能はない。

## 受け入れ条件

| 条件ID | 受け入れ条件 |
|---|---|
| M2-01 | 研修受講者がタスク一覧から編集対象のタスクを選択したとき、システムは対象タスクの現在の情報を表示すること。 |
| M2-02 | 研修受講者がタスク内容を変更して更新を実行したとき、システムはタスク情報を更新すること。 |
| M2-03 | 研修受講者がタスク情報を更新したとき、システムは更新完了メッセージを表示すること。 |
| M2-04 | 研修受講者が更新後にタスク一覧を表示したとき、システムは最新のタスク情報を表示すること。 |
| M2-05 | 研修受講者がタスク名を未入力または空白文字のみで入力するか、期限日を入力せずに更新したとき、システムは更新を拒否し、エラーメッセージを表示し、変更内容を保存しないこと。 |
| M2-06 | 研修受講者がタスク名を100文字（Unicodeコードポイント数）を超えて入力して更新したとき、システムは更新を拒否し、エラーメッセージを表示し、変更内容を保存しないこと。 |
| M2-07 | 研修受講者が説明を200文字（Unicodeコードポイント数）を超えて入力して更新したとき、システムは更新を拒否し、エラーメッセージを表示し、変更内容を保存しないこと。 |
| M2-08 | 研修受講者が期限日に不正な日付を入力して更新したとき、システムは更新を拒否し、エラーメッセージを表示し、変更内容を保存しないこと。 |
| M2-09 | 研修受講者が存在しないタスクを更新しようとしたとき、システムは更新を拒否し、エラーメッセージを表示し、他のタスク情報を変更しないこと。 |

## その他詳細（機能要件/非機能要件）

**機能要件:**
- タスク一覧から対象タスクを選択し、現在の情報を表示する機能
- タスク名、説明、期限日などのタスク情報を編集・保存する機能
- 更新後の情報をタスク一覧に反映する機能
- タスク名と期限日の必須チェック
- タスク名と説明の最大文字数チェック
- 期限日の妥当性チェック
- 更新対象タスクの存在チェック
- 更新成功・入力エラーのメッセージ表示

タスク名は前後の空白文字を除去して保存し、除去後に空となる値は受け付けない。タスク名の上限は除去後、説明の上限は入力値そのものについて、Unicodeコードポイント数で判定する。

**非機能要件:**
- データ整合性の保証（入力検証に失敗した場合、既存情報を変更しない）
- 更新したタスク情報の保持
- 更新結果やエラーを利用者が認識できる画面表示
