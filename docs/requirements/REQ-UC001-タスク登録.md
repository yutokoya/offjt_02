# 要件定義書 REQ-UC001：タスク登録

## 基本情報

- **要求レベル**：Must（必須）
- **利用者**：研修受講者（4名）

## 概要

研修受講者がタスク名、説明、担当者、期限日を入力してタスクを登録できるようにする。

## ユーザーストーリー

- **誰として**：研修受講者として
- **何をしたいか**：タスク名、説明、担当者、期限日を入力してタスクを登録したい
- **その理由**：研修で取り組む作業と期限を整理し、計画的に進めるため

## As-Is（現状）

現行画面はReact/Viteの初期テンプレートであり、タスク登録画面、タスク一覧、タスク情報の保存機能はない。

## 受け入れ条件

| 条件ID | 受け入れ条件 |
|---|---|
| M1-01 | 研修受講者がタスク登録画面を表示したとき、システムはタスク名、説明、担当者、期限日の入力欄を表示すること。 |
| M1-02 | 研修受講者が必須項目であるタスク名と期限日を入力して登録を実行したとき、システムはタスク情報を登録すること。 |
| M1-03 | 研修受講者が有効な内容を入力して登録したとき、システムは登録完了メッセージを表示すること。 |
| M1-04 | 研修受講者がタスクを登録したとき、システムはタスク一覧に新規登録したタスクを表示すること。 |
| M1-05 | 研修受講者がタスク名または期限日を入力せずに登録したとき、システムは登録を拒否し、エラーメッセージを表示し、タスク情報を保存しないこと。 |
| M1-06 | 研修受講者がタスク名の最大文字数を超える値を入力したとき、システムは登録を拒否し、エラーメッセージを表示し、タスク情報を保存しないこと。 |
| M1-07 | 研修受講者が説明欄の最大文字数を超える値を入力したとき、システムは登録を拒否し、エラーメッセージを表示し、タスク情報を保存しないこと。 |
| M1-08 | 研修受講者が期限日に不正な日付を入力したとき、システムは登録を拒否し、エラーメッセージを表示し、タスク情報を保存しないこと。 |

## その他詳細（機能要件/非機能要件）

**機能要件:**
- タスク名、説明、担当者、期限日の入力機能
- タスク名と期限日の必須入力チェック
- タスク名と説明の最大文字数チェック
- 期限日の妥当性チェック
- タスク情報の登録およびタスク一覧への表示
- 登録成功・入力エラーのメッセージ表示

**非機能要件:**
- データ整合性の保証（入力検証に失敗したデータを保存しない）
- 登録済みタスク情報の保持
- エラーや登録結果を利用者が認識できる画面表示
