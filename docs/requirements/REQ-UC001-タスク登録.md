# 要件定義書 REQ-UC001：タスク登録

## 基本情報

- **要求レベル**：Must（必須）
- **利用者**：研修受講者（4名）

## 概要

研修受講者がタスク名、説明、担当者、期限日を入力してタスクを登録できるようにする。

## ユーザーストーリー

- **誰として**：研修受講者として
- **何をしたいか**：タスク名、説明、担当者、期限日を入力してタスクを登録したい
- **その理由**：研修で取り組む作業と期限を整理し、計画的に進めるため

## As-Is（現状）

現在、研修参加者4名はAI開発プロジェクトにおいてタスク管理を個別に実施しており、タスクの依存関係や担当者の状況をリアルタイムに把握できていない。

そのため、

- どのタスクから着手可能か判断するためにメンバー間で確認が必要となる
- 先行タスクの完了待ちによる待機時間が発生する
- 並列で実施可能な作業を見落とし、生産性が低下する
- 作業時間の見積りと実績が管理されておらず、工数超過や遅延の原因分析ができない
- AI利用費用やタスクごとの工数を個別管理しているため、プロジェクト全体の状況を把握しにくい

結果として、研修参加者は開発作業よりも進捗確認や調整に時間を費やしており、タスク着手までの平均待ち時間が約3時間発生している。

## 受け入れ条件

| 条件ID | 受け入れ条件 |
|---|---|
| M1-01 | 研修受講者がタスク登録画面を表示したとき、システムはタスク名、説明、担当者、期限日の入力欄を表示すること。 |
| M1-02 | 研修受講者が必須項目であるタスク名と期限日を入力して登録を実行したとき、システムはタスク情報を登録すること。 |
| M1-03 | 研修受講者が有効な内容を入力して登録したとき、システムは登録完了メッセージを表示すること。 |
| M1-04 | 研修受講者がタスクを登録したとき、システムはタスク一覧に新規登録したタスクを表示すること。 |
| M1-05 | 研修受講者がタスク名を未入力または空白文字のみで入力するか、期限日を入力せずに登録したとき、システムは登録を拒否し、エラーメッセージを表示し、タスク情報を保存しないこと。 |
| M1-06 | 研修受講者がタスク名を100文字（Unicodeコードポイント数）を超えて入力したとき、システムは登録を拒否し、エラーメッセージを表示し、タスク情報を保存しないこと。 |
| M1-07 | 研修受講者が説明を200文字（Unicodeコードポイント数）を超えて入力したとき、システムは登録を拒否し、エラーメッセージを表示し、タスク情報を保存しないこと。 |
| M1-08 | 研修受講者が期限日に不正な日付を入力したとき、システムは登録を拒否し、エラーメッセージを表示し、タスク情報を保存しないこと。 |

## その他詳細（機能要件/非機能要件）

**機能要件:**
- タスク名、説明、担当者、期限日の入力機能
- タスク名と期限日の必須入力チェック
- タスク名と説明の最大文字数チェック
- 期限日の妥当性チェック
- タスク情報の登録およびタスク一覧への表示
- 登録成功・入力エラーのメッセージ表示

タスク名は前後の空白文字を除去して保存し、除去後に空となる値は受け付けない。タスク名の上限は除去後、説明の上限は入力値そのものについて、Unicodeコードポイント数で判定する。

**非機能要件:**
- データ整合性の保証（入力検証に失敗したデータを保存しない）
- 登録済みタスク情報の保持
- エラーや登録結果を利用者が認識できる画面表示
