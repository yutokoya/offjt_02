# 要件定義書 REQ-UC003：タスク削除

## 基本情報

- **要求レベル**：Must（必須）
- **利用者**：研修受講者（4名）

## 概要

研修受講者が削除対象を確認したうえで、登録済みタスクを削除できるようにする。

## ユーザーストーリー

- **誰として**：研修受講者として
- **何をしたいか**：不要または誤って登録したタスクを確認して削除したい
- **その理由**：タスク一覧を最新かつ正確な状態に保つため

## As-Is（現状）

現行画面はReact/Viteの初期テンプレートであり、タスク一覧、削除確認、タスク削除機能はない。

## 受け入れ条件

| 条件ID | 受け入れ条件 |
|---|---|
| M3-01 | 研修受講者がタスク削除を実行したとき、システムは削除確認メッセージを表示すること。 |
| M3-02 | 研修受講者が削除確認画面で削除を確定したとき、システムは対象タスクを削除すること。 |
| M3-03 | 研修受講者がタスクを削除したとき、システムは削除完了メッセージを表示すること。 |
| M3-04 | 研修受講者がタスク一覧を表示したとき、システムは削除済みタスクを表示しないこと。 |
| M3-05 | 研修受講者が削除確認画面でキャンセルしたとき、システムはタスクを削除しないこと。 |
| M3-06 | 研修受講者が存在しないタスクを削除しようとしたとき、システムは削除を拒否し、エラーメッセージを表示し、他のタスク情報を変更しないこと。 |

## その他詳細（機能要件/非機能要件）

**機能要件:**
- 対象タスクの削除確認表示
- 利用者の確定操作による対象タスクの削除
- 削除キャンセル機能
- 削除対象タスクの存在チェック
- 削除済みタスクを通常のタスク一覧に表示しない機能
- 削除完了メッセージの表示

**非機能要件:**
- データ整合性の保証（キャンセル時や削除失敗時にタスクを削除しない）
- 削除結果を利用者が認識できる画面表示
- 削除操作の対象を確認できるユーザーフレンドリーなインターフェース
