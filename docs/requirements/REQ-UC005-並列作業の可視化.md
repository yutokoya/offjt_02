# 要件定義書 REQ-UC005：AI開発の並列作業の可視化

## 基本情報

- **要求レベル**：Should（推奨）
- **利用者**：研修受講者（4名）

## 概要

研修受講者がタスク一覧で各タスクの並列作業状態を確認し、状態による絞り込みを行えるようにする。

## ユーザーストーリー

- **誰として**：研修受講者として
- **何をしたいか**：各タスクが並列作業可能かどうかを一覧で確認し、状態で絞り込みたい
- **その理由**：先行作業による制約を把握し、複数人で効率よく作業を分担するため

## As-Is（現状）

現在、研修参加者4名はAI開発プロジェクトにおいてタスク管理を個別に実施しており、タスクの依存関係や担当者の状況をリアルタイムに把握できていない。

そのため、

- どのタスクから着手可能か判断するためにメンバー間で確認が必要となる
- 先行タスクの完了待ちによる待機時間が発生する
- 並列で実施可能な作業を見落とし、生産性が低下する
- 作業時間の見積りと実績が管理されておらず、工数超過や遅延の原因分析ができない
- AI利用費用やタスクごとの工数を個別管理しているため、プロジェクト全体の状況を把握しにくい

結果として、研修参加者は開発作業よりも進捗確認や調整に時間を費やしており、タスク着手までの平均待ち時間が約3時間発生している。

## 受け入れ条件

| 条件ID | 項目 | 受け入れ条件 |
|---|---|---|
| S2-01 | 依存関係がないタスク | 未着手で、先行タスクが登録されていないタスクが存在するとき、システムは当該タスクを「並列作業可能」と表示すること。 |
| S2-02 | 先行タスクがすべて完了しているタスク | 未着手のタスクに登録されたすべての先行タスクが完了しているとき、システムは当該タスクを「並列作業可能」と表示すること。 |
| S2-03 | 未完了の先行タスクがあるタスク | 未着手のタスクに未完了の先行タスクが1件以上存在するとき、システムは当該タスクを「並列作業不可」と表示すること。 |
| S2-04 | 複数タスクの並列作業可能表示 | 「並列作業可能」と判定されたタスクが複数存在するとき、システムは該当するすべてのタスクについて、同時に「並列作業可能」であることを識別できるように表示すること。 |
| S2-05 | タスク一覧の表示項目 | 研修受講者がタスク一覧画面を表示したとき、システムは各タスクについて、タスク名、ステータス、担当者、期限日および並列作業状態を表示すること。 |
| S2-06 | 最新情報に基づく再判定 | タスクのステータスまたは依存関係が登録、編集もしくは解除された後、研修受講者がタスク一覧画面を再読み込みまたは再度開いたとき、システムは最新のタスク情報および依存関係を基に並列作業状態を再判定して表示すること。 |
| S2-07 | 先行タスク完了後の再判定 | 未完了だった先行タスクが完了した後、研修受講者がタスク一覧画面を再読み込みまたは再度開いたとき、システムは関係する後続タスクの並列作業状態を再判定し、ほかに未完了の先行タスクがなければ、当該後続タスクを「並列作業可能」と表示すること。 |
| S2-08 | 完了済みタスクの扱い | タスクが完了済みであるとき、システムは当該タスクを「並列作業可能」または「並列作業不可」と表示せず、「完了」と表示すること。 |
| S2-09 | 削除済みタスクの扱い | タスクが削除済みであるとき、システムは当該タスクを通常のタスク一覧に表示しないこと。 |
| S2-10 | 並列作業状態による絞り込み | 研修受講者がタスク一覧画面で並列作業状態を絞り込み条件として指定したとき、システムは指定された状態に一致するタスクのみを表示すること。 |
| S2-11 | 絞り込み結果がない場合 | 研修受講者が「並列作業可能」を絞り込み条件として指定し、該当するタスクが存在しないとき、システムは「現在、並列に着手可能なタスクはありません」と画面上に表示すること。 |
| S2-12 | 実行中タスクの扱い | タスクのステータスが実行中であるとき、システムは当該タスクを「並列作業可能」または「並列作業不可」と表示せず、「実行中」と表示すること。 |
| S2-13 | 担当者が未設定のタスク | 並列作業可能なタスクに担当者が設定されていないとき、システムは当該タスクを一覧から除外せず、担当者を「未割当」と表示すること。 |
| S2-14 | 不正な依存関係がある場合 | 自己依存、循環依存または存在しないタスクを参照する依存関係が検出されたとき、システムは不正な依存関係の削除済みでない既存タスク端点（循環依存の場合は循環を構成するすべての削除済みでないタスク）だけを対象として「判定不能」と表示し、対象タスクごとに依存関係の問題理由を画面上に表示すること。 |

## その他詳細（機能要件/非機能要件）

**機能要件:**
- 依存関係およびタスク状態に基づく並列作業状態の判定
- タスク名、ステータス、担当者、期限日、並列作業状態の一覧表示
- 並列作業状態によるタスク一覧の絞り込み
- 完了・実行中・未割当・判定不能の状態表示
- 不正な依存関係の判定不能表示と通知

**非機能要件:**
- 判定時に最新のタスク情報と依存関係を使用すること
- 不正な依存関係による判定不能状態を、並列作業可能・不可と誤って表示しないデータ整合性
- 状態の違いを一覧で識別できるユーザーフレンドリーな表示
