# 要件定義書 REQ-UC006：タスクの依存関係の可視化

## 基本情報

- **要求レベル**：Should（推奨）
- **利用者**：研修受講者（4名）

## 概要

研修受講者がタスク間の先行・後続関係を登録、確認、編集、解除できるようにする。

## ユーザーストーリー

- **誰として**：研修受講者として
- **何をしたいか**：タスク間の先行・後続関係を登録して確認・変更したい
- **その理由**：作業の順序や他のタスクとの関係を把握し、適切な順番で作業を進めるため

## As-Is（現状）

現行画面はReact/Viteの初期テンプレートであり、タスク情報やタスク間の依存関係を管理・表示する機能はない。

## 受け入れ条件

| 条件ID | 項目 | 受け入れ条件 |
|---|---|---|
| S3-01 | 依存関係の登録 | 研修受講者がタスクAを先行タスク、タスクBを後続タスクとして依存関係を登録したとき、システムはA → Bの関係を保存し、後から確認できるようにすること。 |
| S3-02 | 複数の依存関係 | 研修受講者が1つのタスクに複数の先行・後続タスクを登録したとき、システムはすべての関係を個別に保存し、件数上限によって拒否しないこと。 |
| S3-03 | 関係の一覧表示 | 研修受講者がタスクの依存関係を確認するとき、システムは先行・後続の区別と関係先タスクを一覧で表示すること。 |
| S3-04 | 登録結果の維持 | 依存関係の登録・編集が成功した後、研修受講者が画面を再読み込みまたは再度開いたとき、システムは保存済みの関係を表示すること。 |
| S3-05 | 依存関係がないタスク | タスクに依存関係が登録されていないとき、システムは関係がない状態を明確に示し、別のタスクの関係を誤表示しないこと。 |
| S3-06 | 自己依存・循環依存の拒否 | 研修受講者が自己依存または循環する依存関係を登録・編集しようとしたとき、システムは処理を拒否して入力欄内または画面上にエラーを表示すること。 |
| S3-07 | 重複する依存関係 | 同一の先行・後続タスクの関係がすでに登録されているとき、システムは重複を追加せず、既存の関係を維持すること。 |
| S3-08 | 存在しないタスク | 依存関係の登録・編集対象となる先行または後続タスクが存在しないとき、システムは処理を拒否して画面上にエラーを表示すること。 |
| S3-09 | 失敗時の整合性 | 依存関係の登録・編集・解除に失敗したとき、システムは成功したように表示せず、関係の一部だけを変更しないこと。 |
| S3-10 | 依存関係の編集・解除 | 研修受講者が登録済みの依存関係を編集または解除したとき、システムは対象の関係だけを更新または削除し、関係先のタスク自体は削除しないこと。 |
| S3-11 | タスク削除時の依存関係 | 依存関係のあるタスクが削除されたとき、システムは削除対象タスクを先行または後続とする依存関係をすべて削除し、他のタスクと無関係な依存関係を維持すること。削除されたタスクを経由していた関係を自動でつなぎ直さないこと。 |

## その他詳細（機能要件/非機能要件）

**機能要件:**
- 先行タスク・後続タスクの依存関係の登録、編集、解除
- 依存関係および関係先タスクの一覧表示
- 複数の依存関係の登録
- 自己依存、循環依存、存在しないタスクの検証
- 重複する依存関係の登録防止
- 依存関係がない状態の明示
- タスク削除時に削除対象に接続する依存関係だけを削除し、無関係な依存関係を保持する機能（削除されたタスクを経由する関係は自動で再接続しない）

**非機能要件:**
- データ整合性の保証（失敗時に部分更新せず、タスク自体を誤って削除しない）
- 登録・編集した依存関係の永続化
- 先行・後続の関係を区別して確認できるユーザーフレンドリーな表示
