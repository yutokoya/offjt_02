# 要件定義書 REQ-UC004：各タスクの作業時間の可視化

## 基本情報

- **要求レベル**：Should（推奨）
- **利用者**：研修受講者（4名）

## 概要

研修受講者がタスクごとの見積り時間と、日付ごとの実績および実績合計を登録・確認・編集できるようにする。

## ユーザーストーリー

- **誰として**：研修受講者として
- **何をしたいか**：タスクごとの見積り時間と日付ごとの実績時間を記録し、実績合計を確認したい
- **その理由**：作業の進捗や見積りとの差を把握し、残りの作業を計画するため

## As-Is（現状）

現在、研修参加者4名はAI開発プロジェクトにおいてタスク管理を個別に実施しており、タスクの依存関係や担当者の状況をリアルタイムに把握できていない。

そのため、

- どのタスクから着手可能か判断するためにメンバー間で確認が必要となる
- 先行タスクの完了待ちによる待機時間が発生する
- 並列で実施可能な作業を見落とし、生産性が低下する
- 作業時間の見積りと実績が管理されておらず、工数超過や遅延の原因分析ができない
- AI利用費用やタスクごとの工数を個別管理しているため、プロジェクト全体の状況を把握しにくい

結果として、研修参加者は開発作業よりも進捗確認や調整に時間を費やしており、タスク着手までの平均待ち時間が約3時間発生している。

## 受け入れ条件

| 条件ID | 項目 | 受け入れ条件 |
|---|---|---|
| S1-01 | 見積り登録 | 研修受講者がタスクに有効な見積り時間を登録したとき、システムはその値を当該タスクの見積りとして保存し、画面に表示すること。 |
| S1-02 | 見積り編集 | 研修受講者が登録済みの見積り時間を変更したとき、システムは見積りだけを更新し、当該タスクの実績記録・実績合計および他タスクのデータを変更しないこと。 |
| S1-03 | 日付付き実績の記録 | 研修受講者がタスクの実績時間と日付を入力して登録したとき、システムは入力された分数と日付をそのタスクの実績記録として保存すること。 |
| S1-04 | 実績時間の累積 | タスクに実績記録が追加されたとき、システムはそのタスクの全実績記録を累積し、実績合計として表示すること。 |
| S1-05 | 実績記録の編集 | 研修受講者が登録済み実績の分数または日付を編集したとき、システムは対象記録を更新し、実績合計を更新後の全記録の合計に一致させること。 |
| S1-06 | 時間情報の識別表示 | 研修受講者がタスクの時間情報を確認するとき、システムは見積りと実績合計を区別して表示し、登録済みの各実績について日付と分数を確認・識別できるようにすること。 |
| S1-07 | 保存後の維持 | 時間情報の登録または編集が成功した後、研修受講者が画面を再読み込みまたは再度開いたとき、システムは保存済みの値を表示すること。 |
| S1-08 | 時間入力の境界値 | 時間を入力するとき、システムは0以上の整数分を受け付け、製品上の最大値を設けないこと。 |
| S1-09 | 不正な時間値 | 時間の入力値が数値でない、負数である、または整数分でないとき、システムは入力を拒否し、理由を利用者に示し、保存済みデータを変更しないこと。 |
| S1-10 | 日付の入力検証 | 実績の登録または編集で日付が未入力、実在しない日付、または未来日であるとき、システムは保存を拒否し、既存データを変更しないこと。 |
| S1-11 | 失敗時の整合性 | 登録または編集が失敗したとき、システムは成功したように表示せず、対象データを一部だけ更新しないこと。 |
| S1-12 | 対象タスクが存在しない場合 | 時間情報の登録・編集対象タスクが存在しないとき、システムは処理を拒否して画面上にエラーを表示し、他のタスクの時間情報を変更しないこと。 |
| S1-13 | 見積りと実績の比較 | 研修受講者がタスクの時間情報を確認するとき、見積り時間と実績合計の両方が登録されていれば、システムは両者の差異を同じ画面に表示し、どちらが大きいか判別できるようにすること。見積りまたは実績が変更されたときは、表示する差異も更新すること。いずれかが未登録の場合は差異の数値を表示せず、「未算出」と表示すること。見積り0分は登録済みとして扱い、実績に0分の記録が1件以上ある場合も実績合計0分を登録済みとして差異を算出すること。 |

## その他詳細（機能要件/非機能要件）

**機能要件:**
- タスクごとの見積り時間の登録・編集・表示
- 日付と分数を含む実績時間の登録・編集
- 実績記録の累積および実績合計の表示
- 見積り時間と実績時間の区別表示
- 見積りと実績合計の比較、および差異の表示・更新
- 時間値（0以上の整数分）と実績日（未入力・実在しない日付・未来日）の入力検証

**非機能要件:**
- データ整合性の保証（失敗時に部分更新せず、既存データを維持する）
- 登録・編集した時間情報の永続化
- タスクごとの見積り・実績・差異および実績日を区別して確認できるユーザーフレンドリーな表示
