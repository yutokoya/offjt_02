## 背景・課題

前回の研修で利用した技術を活用し、開発経験が浅いメンバーにも導入しやすい構成にする。

## 決定

- フロントエンド: React + TypeScript + Vite
- バックエンド: Java + Spring Boot（REST API）
- データベース: PostgreSQL
- DB変更管理: Flyway（DBスキーマの変更をバージョン管理し、順番に適用するツール）
- CI: GitHub Actionsでフロントエンド・バックエンドのビルド、テスト、lintを実行する

## 選定理由

| 観点 | 確認結果・根拠 |
|---|---|
| 前回の研修での利用経験 | 前回の研修で利用した技術を活用し、導入・学習の負担を抑える |
| 開発経験が浅いメンバーへの導入しやすさ | 前回の研修で利用した技術をベースに、扱いやすい構成とする |
