# クイックスタート: タスク更新の検証

## 事前準備

- Java 21、Node.js 24、pnpm 10
- DockerとPostgreSQL 17
- 更新対象となる既存の有効なタスクレコード（本機能では登録画面/APIを追加しない）

## 開発用データベースの起動

リポジトリのルートで実行する:

```bash
docker compose up -d postgres
```

## 自動検証

依存関係の初回セットアップ時または変更時に実行する:

```bash
pnpm --dir frontend install --frozen-lockfile
```

バックエンドの検証:

```bash
cd backend
./mvnw test
```

フロントエンドの検証:

```bash
pnpm --dir frontend test
pnpm --dir frontend build
```

## 受け入れ確認の手順

1. 開発用データベースに有効なタスクを用意する。データ作成には既存の登録機能またはテスト用fixtureを使い、本機能に登録操作を追加しない。
2. フロントエンドでタスク一覧を表示し、対象行の「編集」を選ぶ。
3. 登録画面とは別の更新画面が表示され、現在のタスク名・説明・期限日が入力欄に表示されることを確認する。
4. 有効な内容に変更して保存する。完了メッセージが表示され、一覧で最新値を確認する。
5. 空白だけのタスク名、100 Unicodeコードポイントを超えるタスク名、200 Unicodeコードポイントを超える説明、未入力または実在しない期限日で更新を試す。エラーが表示され、保存済み値が変わらないことを確認する。
6. 存在しないタスクIDで取得・更新を試し、404相当のエラーとなり、他のタスクに影響しないことを確認する。

CIと同等の検証は、リポジトリのルートで`bash scripts/gate.sh verify`を実行する。必要なPostgreSQLが起動していることを確認する。
