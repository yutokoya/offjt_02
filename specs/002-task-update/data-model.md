# データモデル: タスク更新

本機能は共通タスクモデルの既存レコードを変更する。フィールド定義と制約は[共通データモデル](../../docs/design/data-model.md)に従う。

## エンティティ: Task（タスク）

| 属性 | 意味 | 更新時の規則 |
|---|---|---|
| `taskId` | タスクの一意な識別子 | 更新対象の特定に使用し、変更しない |
| `taskName` | タスク名 | 必須。前後の空白を除去して保存し、除去後1〜100 Unicodeコードポイント |
| `description` | 説明 | 任意。省略または`null`は空として扱う。入力値は最大200 Unicodeコードポイント |
| `dueDate` | 期限日 | 必須。実在する日付を保存する |
| `deletedAt` | 論理削除日時 | 値があるタスクは更新対象にしない |

担当者や将来追加される他の属性が永続化されている場合も、本機能のリクエストに含めず、タスク更新時に変更しない。

## 状態と整合性

- 更新前の状態は、指定IDの有効なタスクレコードである。
- 成功時は`taskName`、`description`、`dueDate`のみを入力値で置き換える。他の属性と識別子は維持する。
- 対象がない、論理削除済み、または入力検証失敗の場合は保存済みデータを変更しない。
- 1回の更新は不可分に処理する。更新後にタスク一覧を取得すると新しい値が表示される。
- 本機能はタスクの新規作成、物理削除、削除済みレコードの復元を行わない。
