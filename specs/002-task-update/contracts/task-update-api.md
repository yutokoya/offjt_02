# タスク更新API契約

共通エラー形式・日付形式・フィールド制約は[API契約](../../../docs/design/api-contract.md)に従う。データ形式にはJSONを使用する。

## 編集対象タスクの取得

`GET /api/tasks/{taskId}`

- `200 OK`: 対象タスクの現在値を返す。
- `404 Not Found`: 対象が存在しない、または論理削除済み。
- 登録画面とは別の更新画面を開く際に利用する。画面には取得した値を表示する。

## タスクの更新

`PUT /api/tasks/{taskId}`

要求:

```json
{
  "taskName": "API契約を確認する",
  "description": "入出力とエラー応答を確認する",
  "dueDate": "2026-11-18"
}
```

- `taskName`: 必須。前後のUnicode空白を除去して保存し、空文字を拒否する。除去後100 Unicodeコードポイントを超える値は拒否する。
- `description`: 任意。省略または`null`は空として扱う。入力値が200 Unicodeコードポイントを超える場合は拒否する。
- `dueDate`: 必須。`YYYY-MM-DD`形式の実在日付を受け付ける。
- これら以外のタスク属性は更新リクエストに含めず、変更しない。

応答:

| ステータス | 意味 |
|---|---|
| `200 OK` | 更新後のタスクを返す |
| `400 Bad Request` | 必須項目・文字数・日付の検証失敗。共通エラー形式を返し、変更を保存しない |
| `404 Not Found` | 対象が存在しない、または論理削除済み。他のタスクを変更しない |

更新と検証は一処理として行い、失敗時に部分更新を残さない。登録用`POST /api/tasks`と削除用`DELETE`は本機能の契約範囲外。

## 画面操作の契約

- タスク一覧の各行から「編集」操作で対象タスクの更新画面を開く。
- 更新画面は登録画面と分け、取得した現在値を入力欄に表示する。
- 保存成功時は完了メッセージを表示し、一覧で最新値を確認できる。
- 入力またはAPIエラーは利用者に表示し、エラー時は保存成功として扱わない。
